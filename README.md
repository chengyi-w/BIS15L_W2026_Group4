# Analysis of a Phase III Trial of Camrelizumab With Chemoradiotherapy in Nasopharyngeal Carcinoma

This repository contains our course project on a phase III randomized trial in high-risk nasopharyngeal carcinoma. We use the published study dataset to explore treatment outcomes, create visualizations, and perform survival analysis.

## Data source

The dataset used in this project is from the Dryad repository associated with the study:

* DOI: `10.5061/dryad.3j9kd51zg`

## Original paper

**Camrelizumab concurrent with chemoradiotherapy and as maintenance treatment for high-risk nasopharyngeal carcinoma: a multicentre, open-label, parallel-group, phase 3 randomised controlled trial**  
*BMJ* (2026), 392:e085863  
DOI: `10.1136/bmj-2025-085863`

## Project goal

The goal of this project is to explore the dataset and visualize the key findings from the study.
